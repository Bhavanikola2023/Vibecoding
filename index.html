🚀 VIBE Coding Guide

Build Your ePortfolio in 2 Hours

Welcome to VIBE Coding

Learn to build a professional ePortfolio web page in just 2 hours using HTML, CSS, and JavaScript. No frameworks. No external libraries. Just pure web development.

What is VIBE?

VIBE is a design thinking methodology that guides your coding process:

  • Visualize: Understand the requirements and plan your design
  • Ideate: Brainstorm features and content
  • Build: Write code to bring your ideas to life
  • Evaluate/Enhance: Test, refine, and improve

How it is done

Steps Stage Activity
Step 1 Visualize Complete PRD; sketch wireframe
Step 2 Ideate Brainstorm content; design layout
Step 3 Build Code HTML, CSS, and JavaScript
Step 4 Evaluate/Enhance Test; peer review; improve

By the End, You'll Have:

✅ A Live Website

A single HTML file with embedded CSS and JavaScript

🎨 Professional Design

Clean layout, responsive, and ready to share

⚙️ Interactive Features

Buttons, toggles, smooth scrolling, and more

💡 Tip: Start simple. You can always add more features later. The goal is to complete a working v1 in 2 hours!

Stage 1: Visualize

Goal: Understand the requirements and constraints. Define the scope.

What You'll Do

  1. Read the Project Requirements Document (PRD)
  2. Identify what MUST be included
  3. Understand the constraints
  4. Sketch a wireframe on paper

Project Requirements Document (PRD)

📋 PROJECT REQUIREMENTS DOCUMENT

Project Name: Personal ePortfolio Web Page

Goal: Create a single-page, interactive ePortfolio that showcases your resume in a visually appealing, user-friendly format.

Audience: Potential employers, clients, or academic reviewers

Core Requirements:

  • Header section with name and professional title
  • Profile photo or avatar
  • About/Summary section (2-3 sentences)
  • Skills section (list at least 5 skills)
  • Experience or Projects section (at least 2 entries)
  • Contact information
  • Footer with copyright

Nice-to-Have Features:

  • Dark/light theme toggle
  • Hover effects on buttons
  • Smooth scrolling navigation
  • Animated elements (fade-in, slide-in)
  • Responsive design (mobile & desktop)

Technical Constraints:

  • Single HTML file (no external files)
  • HTML5 semantic markup
  • Embedded CSS in <style> tags
  • Vanilla JavaScript (no frameworks)
  • Must run in any modern browser

Wireframe Your Layout

Sketch this on paper:

┌─────────────────────────────────────┐ │ HEADER / TITLE │ │ (Your Name & Title) │ ├─────────────────────────────────────┤ │ │ │ PROFILE SECTION │ │ (Photo + Professional Summary) │ │ │ ├─────────────────────────────────────┤ │ │ │ SKILLS SECTION │ │ (5-10 Skills as Tags) │ │ │ ├─────────────────────────────────────┤ │ │ │ PROJECTS/EXPERIENCE SECTION │ │ (2-3 Cards with Descriptions) │ │ │ ├─────────────────────────────────────┤ │ │ │ CONTACT SECTION │ │ (Email, LinkedIn, GitHub, etc.) │ │ │ ├─────────────────────────────────────┤ │ FOOTER │ │ (Copyright Notice) │ └─────────────────────────────────────┘
✏️ Pro Tip: Don't overthink the wireframe. A simple sketch on paper is enough. Focus on the layout and structure.

Stage 2: Ideate

Goal: Plan your design, structure, and layout before coding.

Step 1: Define Your Design (15 minutes)

🎨 Color Scheme ▼

Choose 2-3 colors:

  • Primary Color: Your main brand color (used for headers, buttons)
  • Secondary Color: A complementary color
  • Accent Color: For highlights and interactive elements

Example schemes:

Modern Purple
Professional Blue
Bold Red
🔤 Typography ▼

Pick 1-2 fonts. Web-safe options:

  • Arial / Helvetica (clean, professional)
  • Georgia / Times (elegant, classic)
  • Courier New (monospace, technical)
  • Segoe UI / Tahoma (modern)
🎯 Layout & Spacing ▼

Decide on:

  • Margins: 20-40px around sections
  • Padding: 15-25px inside cards
  • Alignment: Center for headers, left for body text
  • Max-width: 800px to keep content readable

Step 2: Plan Interactive Elements (10 minutes)

What will users click or interact with? Pick at least 1:

Dark/Light Mode Toggle

Button to switch between themes

Expand/Collapse

Show/hide skills or projects

Smooth Scroll

Click to jump to sections

Hover Effects

Buttons change color on hover

Filter Buttons

Show/hide skills by category

Contact Form

Simple form or email link

Step 3: Prepare Your Content (15 minutes)

  1. Professional Summary: Write 2-3 sentences about yourself
  2. Skills List: Write 5-10 skills you have
  3. Projects/Experience: Prepare 2-3 entries with descriptions
  4. Contact Info: Email, LinkedIn, GitHub, portfolio, etc.
  5. Profile Photo: Find or create a photo (or use a placeholder)

Need Help with Content?

💭 "I'm creating an ePortfolio. My name is [Your Name], and I'm a [role/student]. My skills are [list]. Create a professional 2-sentence summary for me."
💡 Tip: Use placeholder images from https://via.placeholder.com/150 for now. You can replace them later.

Step 3: Add JavaScript Interactivity

Choose one or more interactive features:

🌙 Option 1: Dark/Light Mode Toggle ▼ 
<script>
    const toggleBtn = document.createElement('button');
    toggleBtn.textContent = '🌙 Dark Mode';
    toggleBtn.style.position = 'fixed';
    toggleBtn.style.top = '20px';
    toggleBtn.style.right = '20px';
    toggleBtn.style.padding = '10px 15px';
    toggleBtn.style.backgroundColor = '#3498db';
    toggleBtn.style.color = 'white';
    toggleBtn.style.border = 'none';
    toggleBtn.style.cursor = 'pointer';
    document.body.appendChild(toggleBtn);

    let isDark = false;

    toggleBtn.addEventListener('click', function() {
        isDark = !isDark;
        if (isDark) {
            document.body.style.backgroundColor = '#222';
            document.body.style.color = '#fff';
            toggleBtn.textContent = '☀️ Light Mode';
            document.querySelectorAll('section').forEach(s => {
                s.style.backgroundColor = '#333';
            });
        } else {
            document.body.style.backgroundColor = '#f4f4f4';
            document.body.style.color = '#333';
            toggleBtn.textContent = '🌙 Dark Mode';
            document.querySelectorAll('section').forEach(s => {
                s.style.backgroundColor = 'white';
            });
        }
    });
</script>
✨ Option 2: Smooth Scroll Navigation ▼ 
<script>
    const links = document.querySelectorAll('a[href^="#"]');

    links.forEach(link => {
        link.addEventListener('click', function(e) {
            e.preventDefault();
            const target = document.querySelector(this.getAttribute('href'));
            if (target) {
                target.scrollIntoView({ behavior: 'smooth', block: 'start' });
            }
        });
    });
</script>
👁️ Option 3: Show/Hide Skills ▼ 
<script>
    const skillsSection = document.getElementById('skills');
    const skillsList = document.querySelector('.skill-list');
    const btn = document.createElement('button');

    btn.textContent = 'Show More';
    btn.style.marginTop = '15px';
    btn.style.padding = '10px 20px';
    btn.style.backgroundColor = '#3498db';
    btn.style.color = 'white';
    btn.style.border = 'none';
    btn.style.cursor = 'pointer';

    skillsSection.appendChild(btn);

    let showing = true;

    btn.addEventListener('click', function() {
        showing = !showing;
        skillsList.style.display = showing ? 'flex' : 'none';
        btn.textContent = showing ? 'Show More' : 'Show Less';
    });
</script>
💡 How to Use These Code Blocks:
  1. Click "Copy" to copy the code
  2. Paste it into your HTML file inside the <script> tags
  3. Save the file and refresh your browser
  4. Test to make sure it works!

Stage 4: Evaluate & Enhance

Goal: Test your code, find issues, and improve the design.

Testing Checklist

How to Test in Your Browser

  1. Open Developer Tools (press F12)
  2. Click the "Console" tab
  3. Check for any red error messages
  4. Press Ctrl+Shift+M to test mobile view
  5. Click all buttons and links to test functionality

Final Tips for Success

✓ Start simple. Don't overcomplicate your first version.
✓ Test frequently. Save and refresh after each change.
✓ Use placeholder content. Get the structure right first.
✓ Keep colors consistent. Use the same scheme throughout.
✓ Mobile matters. Test on smaller screens.
✓ Iterate, don't perfect. Launch v1, then enhance it later.
